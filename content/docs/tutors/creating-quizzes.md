# Creating Your First Quiz

Tutors can build robust assessments using our intuitive editor and AI-powered tools.

## The Creation Flow

1. **Initialize**: Navigate to "My Quizzes" and click "New Assessment".
2. **Metadata**: Set the title, description, and time limit.
3. **Questions**: Use the manual editor or "AI Assist".

## Using AI Assist

Our AI can help you generate questions from:
- **Topics**: e.g., "Introductory Calculus".
- **Raw Text**: Paste your lecture notes or textbook excerpts.
- **File Upload**: Supported for PDF and Word documents.

## Integrity Settings

You can customize the level of security for each quiz:
- **Strict Mode**: Full browser activity monitoring.
- **Shuffle**: Automatically randomize question and option order.
- **IP Masking**: Prevent multiple attempts from the same network.
